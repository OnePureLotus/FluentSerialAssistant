本版本增加 Modbus 站号探测，并简化终端顶栏。

### Modbus RTU

- 站号下方可勾选 **站号探测**；显示探测间隔（默认 500 ms）后点 **发送**，将按当前功能与寄存器参数依次向站号 0–255 发帧。再点 **停止探测**、取消勾选或断开端口可中止。是否在总线上有回复请查看右侧终端日志。

### 终端

- 日志区顶栏去掉主题/语言快捷按钮，增加 **清日志**（扫帚图标），快速清空终端内容。主题与语言请在 **设置** 中修改。

## English

- **Modbus RTU:** optional station scan (slave 0–255) with configurable interval; judge responses in the terminal log.
- **Terminal header:** removed theme/language shortcuts; added **Clear log** (broom). Use Settings for theme and language.

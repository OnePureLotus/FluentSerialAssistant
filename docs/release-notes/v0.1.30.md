本版本改进常用命令的添加、编辑与文件夹交互。

- 固定命令：列表内编辑命令内容；名称保存后以标题展示，打勾确认，工具栏「编辑」可改名称。
- 模板命令：添加/编辑仍用对话框；列表恢复只读标题与参数输入，不在列表里改模板正文。
- 发送预览行右侧可选 CR/LF，与底部发送区一致。
- 文件夹：只有展开按钮会折叠/展开，点击标题等区域仅选中，便于向该文件夹添加命令。

## English

Quick Commands UX: fixed commands edit payload in the list; names show as titles after confirm; templates use a dialog while the list shows title plus parameter fields only; CR/LF on the preview row; folder headers select on click and expand only via the chevron.

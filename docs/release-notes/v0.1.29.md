本版本修复常用命令「发送预览」随侧栏宽度换行的问题。

- 预览按卡片可用宽度自动折行；拖动侧栏加宽时行数可减少，变窄时自动多行。
- 预览以正文样式显示（无输入框边框），长 AT 命令或 HEX 不再把面板挤出窗口。

## English

Fixes quick-command send preview wrapping when the panel is resized.

- Preview wraps to the available card width; widening the side panel merges lines, narrowing splits them.
- Plain body text styling (no input box chrome); long payloads no longer overflow the panel.

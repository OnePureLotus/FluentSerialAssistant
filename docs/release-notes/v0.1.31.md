本版本改进发送区、终端显示与常用命令列表布局。

### 发送与终端

- 发送区支持文本 / HEX 切换；HEX 输入校验，删除键等可正常使用。
- 终端发送行按当时的发送方式显示（文本或 HEX），与接收区显示模式独立。

### 工作台侧栏

- 「协议模板」移到「发送设置」之后。

### 常用命令

- 每条命令可折叠：折叠后仅保留名称、展开与发送；固定命令折叠后可直接点发送。
- 发送模式不再单独设置，与主界面「HEX 发送」一致。
- 折叠行发送按钮与展开按钮对齐；换行后缀在展开按钮左侧，展开钮位置不随展开状态跳动。

## English

- Send box: text/HEX toggle (SSCom-style) with HEX validation; navigation keys including Delete work in HEX mode.
- Terminal: TX lines show as text or HEX based on how they were sent; RX follows the display mode.
- Sidebar: Protocol templates after send settings.
- Quick commands: per-command collapse (name + expand + send); fixed commands can send while collapsed; send uses the main **HEX send** checkbox; aligned send/expand buttons; line-ending hint sits left of the expand control.

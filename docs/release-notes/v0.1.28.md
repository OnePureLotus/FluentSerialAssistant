发送区快捷设置、终端与输入可拖动分割，以及常用命令面板优化。

- 发送输入框下方同一行：接收/发送显示模式、后缀 CR/LF、时间戳与发送按钮。
- 终端记录区与发送区之间可拖动分界线调整高度，比例会记住。
- 常用命令顶栏与排序交互调整（见 0.1.27 变更说明）。
- 新建模板命令默认只有一个参数；编辑时可删除多余的参数行。
- 首次从程序目录迁移旧版 `FluentSerialAssistant.ini` 时，不再把其中的测试常用命令写入用户配置。

## English

Quick send settings, a draggable split between the terminal and send area, and quick-commands panel updates.

- One row under the send box: RX/TX display mode, CR/LF suffix, timestamp, and Send.
- Drag the splitter between the terminal and send section; the ratio is saved.
- Quick-commands toolbar and reordering tweaks (see 0.1.27 notes).
- New template commands default to one parameter; each parameter row can be removed in the editor.
- Migrating legacy `FluentSerialAssistant.ini` from the app folder no longer copies dev quick commands into user settings.
